# Bản nháp lưu trữ

`aistudio/` chứa các bản HTML/JS, nội dung dán thử, `metadata.json` và hai bản icon `meta-app-icon.*` từ giai đoạn AI Studio. Không tìm thấy mã hoặc cấu hình hiện tại tham chiếu các file này. Chúng được giữ để đối chiếu và có thể khôi phục nếu cần, ngoài `public/` để website không phục vụ trực tiếp.
