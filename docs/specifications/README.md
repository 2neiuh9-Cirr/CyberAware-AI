# Các bản SRS

- `SRS_CyberAware_AI_Quy_trinh_theo_khung_final.pdf`: bản PDF cuối để đọc và chia sẻ.
- `SRS_CyberAware_AI_Quy_trinh_theo_khung.docx`: bản Word có thể chỉnh sửa của tài liệu theo khung quy trình; lưu cùng PDF để cập nhật sau này.
- `SRS_CyberAware_AI.docx`: bản SRS cũ để tham khảo lịch sử.

Tên “final” và thời gian tạo file được dùng để xác định bản PDF hiện hành. Nếu nội dung Word được cập nhật sau, cần xuất lại PDF và cập nhật ghi chú này.
